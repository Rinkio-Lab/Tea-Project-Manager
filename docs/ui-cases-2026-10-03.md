# Tea PM 2.0 界面/交互借鉴清单（2026-10-03）

## 1. Godot 项目管理器
来源：https://docs.godotengine.org/en/4.7/tutorials/editor/project_manager.html

- 双击卡片直接打开项目，列表默认按"最近编辑"排序，不用翻菜单。
- 顶部一排动词入口：创建 / 导入 / 扫描 / 筛选；重命名、打标签、移除收进项悬停或右键菜单。
- 设置固定右上角，集中放主题、配色、显示缩放，与项目列表区分离。
- 移除只删索引条目、不删磁盘文件夹，并二次确认（Godot Launcher 同款行为）。

## 2. Linear 视图切换与快捷键
来源：https://linear.app/docs/display-options ；https://linear.app/docs/peek

- 一个快捷键在网格/列表间切换，切换图标常驻视图右上角。
- Ctrl+K 命令面板：模糊搜项目 + 最近操作叠加，输入即直达。
- j/k 移动焦点、Enter 打开、空格呼出详情速览（Peek），不跳新页。
- 右侧栏只放筛选条件与健康度徽章，不堆导航。

## 3. Dribbble PM Dashboard KPI 卡
来源：https://dribbble.com/shots/26997920-Project-Management-Dashboard

- 顶部一排 4 张大数字卡：全部 / 进行中 / 已完成 / 逾期，一眼看总数。
- 项目卡片内置进度条、截止日、任务数、状态徽章（On Track / At Risk）。
- 状态色固定语义：绿=正常、黄=需注意、红=紧急，配色不随主题乱动。
- 配一个环形图展示完成占比，不做花哨大图。

## 4. roost（本地 TUI 项目面板）
来源：https://phpgao.github.io/roost/

- 项目+会话双列表，搜索框实时过滤，输入即筛。
- Tab 切换平台筛选，支持批量多选后一键移除。
- 每分钟自动刷新状态，不靠手动点刷新。
- 纯键盘导航，方向键即可完成打开/筛选/删除。

## 5. 微文案：动词开头、拒绝"AI 味"
来源：https://www.woshipm.com/ucd/5673267.html ；https://markdowners.com/m/markdowners/ux-microcopy-rules

- 按钮一律"动词+对象"：打开项目、导入路径、移除条目，禁用"提交/确定/下一步"。
- 危险与可逆操作分开：移除索引 vs 删除文件夹，后者红色、二次确认。
- 空状态给动作不给鸡汤："还没有项目，先创建或导入一个"。
- 按钮 2-4 个词，句子大小写，不写"智能地为您……"。

## 综合建议

- **网格卡片**：hover 才浮出"打开/定位/移除"按钮，常态只留项目名、路径、最近编辑时间、状态徽章。
- **表格视图**：首列常驻名称与路径，j/k 键盘移动选中，Enter 直接打开。
- **仪表盘**：顶部 4 张 KPI 大数字卡（总数/进行中/已完成/超 30 天未动），下方直接接进度条列表。
- **详情面板**：右侧滑出式 Peek，空格呼出，显示路径、Git 分支、最近活动，不跳新页。
